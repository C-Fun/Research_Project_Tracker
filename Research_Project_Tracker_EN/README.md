# Research Project Tracker

> To start a new project, duplicate this entire folder. Fill in `project_overview.md` and replace all `YYYY-MM-DD` placeholders as you go.

---

## Folder Structure

| Folder | Purpose |
| ------ | ------- |
| `00_admin/` | Grants, IRB/ethics, contracts |
| `01_literature/` | PDFs and reading notes |
| `02_design/` | Research design docs, pre-registration |
| `03_data/raw/` | Original data — **read-only, never modify** |
| `03_data/processed/` | Intermediate data, generated by code only |
| `04_code/` | Analysis scripts, named by module number |
| `05_results/` | Output tables and figures |
| `06_writing/` | Paper drafts |
| `07_presentations/` | Slides |

## Core Files

| File | Purpose | When to Update |
| ---- | ------- | -------------- |
| `project_overview.md` | Project control panel | Weekly |
| `decision_log.md` | Key decision record | Every time a key decision is made |
| `task_list.md` | Next / Waiting / Done board | Daily or after every meeting |
| `meeting_notes.md` | Structured meeting notes | Within 15 min of meeting ending |
| `source_log.md` | Data sources + variable dictionary | Whenever data changes |
| `result_log.md` | Results tied to code versions | Every time a key result is produced |
| `presentation_feedback.md` | Audience questions and feedback | After every presentation |

## Weekly Maintenance (30 minutes)

- [ ] Update "Next Steps This Week" in `project_overview.md`
- [ ] Move action items from meeting notes into `task_list.md`
- [ ] Log this week's key decisions in `decision_log.md`
- [ ] Log new key results in `result_log.md`
- [ ] Clear temp files from desktop and downloads
- [ ] Archive abandoned files

## Ground Rules

1. Raw data is read-only — never modify files in `03_data/raw/`
2. All intermediate data must be generated by code
3. Any manual data change must be logged in `source_log.md`
4. All key results must be logged in `result_log.md`
5. All key decisions must be logged in `decision_log.md`
6. Meeting notes within 15 minutes of the meeting ending
